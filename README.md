# Text Mosaic Generator

## Introduction

Text Mosaic Generator is an application that transforms images into a mosaic of text. The app uses the Python Imaging Library (PIL) to overlay text onto an image, adjusting it to match the image's colors and contrast. This tool is perfect for creating artistic renditions of photographs or graphics using your favorite quotes or text.

## Features

- Image resizing to a target width while maintaining aspect ratio.
- Text overlay that matches the underlying color and contrast of the image.
- Customizable text and image input.
- Support for various image formats.

## Requirements

- Python 3.x
- PIL (Pillow)
